glissando · link-function expansion

Implements LINK-1…LINK-6 — probit, complementary log-log, inverse, inverse-square, sqrt, and cauchit / shifted links. The smallest and most mechanical of the remaining workstreams: it extends a 4-impl pattern with no new trait machinery. The mu_eta hinge it needs (TRAIT-2) already shipped.

Touches: src/distributions/links.rs (the only file with real logic), src/distributions/mod.rs (re-export line), and the by-name link lookup used by default_link / the JSON facade.

The pattern you are extending

A link function g maps a response-scale parameter μ to the linear predictor η = g(μ). Every link in glissando is a zero-field unit struct that implements the Link trait (src/distributions/links.rs:15) with three methods:

pub trait Link: Debug + Send + Sync {
    fn link(&self, mu: f64) -> f64;        // η = g(μ)
    fn inv_link(&self, eta: f64) -> f64;   // μ = g⁻¹(η)
    fn mu_eta(&self, eta: f64) -> f64 {    // dμ/dη = (g⁻¹)'(η)
        let h = 1e-6;                       // default: symmetric finite diff
        (self.inv_link(eta + h) - self.inv_link(eta - h)) / (2.0 * h)
    }
}

The IRLS inner loop is η-scale: the generic weight is mu_eta(η)² · i_θ (Fisher info on the natural scale). Supplying mu_eta analytically is what makes a link usable in scoring — the default finite difference works but is slower and noisier. The four existing links (IdentityLink, LogLink, LogitLink, FlooredLogLink, links.rs:37–123) are your copy-paste templates; LogitLink at links.rs:109 is the closest analog for a bounded link.

Saturation guards (mandatory). Reuse the module constants at links.rs:8–12: MIN_POSITIVE = 1e-10 (clamp μ off 0), MAX_ETA = 30.0 / MIN_ETA = −30.0 (clamp η to keep exp finite). Every new link must clamp the same way LogLink/LogitLink do, or fitting blows up at the boundaries.

Build order

  1. Add the six structs in links.rs. Each is struct XLink; + impl Link for XLink with a closed-form mu_eta. The math per link:
    LINK-1Probit — link = Φ⁻¹(μ), inv_link = Φ(η), mu_eta = φ(η). Needs the standard-normal CDF Φ and PDF φ. Glissando already evaluates Φ inside Gaussian cdf (src/distributions/gaussian.rs) and has special functions in src/math.rs — reuse, don't reimplement erf.
    LINK-2cloglog — link = ln(−ln(1−μ)), inv_link = 1 − exp(−eᶦ), mu_eta = exp(η − eᶦ) (where eᶦ = exp(η)). Clamp η to [MIN_ETA, MAX_ETA] before exp.
    LINK-3inverse — link = 1/μ, inv_link = 1/η, mu_eta = −1/η². Guard η away from 0 with MIN_POSITIVE.
    LINK-4inverse-square — link = 1/μ², inv_link = η^(−1/2), mu_eta = −½·η^(−3/2). η stays positive.
    LINK-5sqrt — link = √μ, inv_link = η², mu_eta = 2η. The Poisson variance-stabilizing link.
    LINK-6cauchit — link = tan(π(μ−½)), inv_link = ½ + atan(η)/π, mu_eta = 1/(π(1+η²)); plus shifted/"own" bounded-logit variants (a logit on (μ−a)/(b−a)) carrying the bounds as struct fields — the one case that is not a unit struct.
  2. Re-export them from src/distributions/mod.rs:13 — extend the existing pub use links::{FlooredLogLink, IdentityLink, Link, LogLink, LogitLink}; line.
  3. Wire selection by name. Add the new variants everywhere a link is chosen by string: per-family default_link impls that should adopt a new canonical link (e.g. let Gamma offer LINK-3, Poisson LINK-5), and the JSON link parser so a saved/loaded model and the bindings can name "probit", "cloglog", etc. Grep for the existing link strings ("identity", "log", "logit") to find every switch that needs a new arm.

Tests & reference oracle

Extend the existing mod tests in links.rs:125–283 — it already has the scaffolding:

  • Analytic vs finite-difference mu_eta. Add every new link to the [&dyn Link; N] array in mu_eta_analytic_matches_finite_difference (links.rs:188). It reuses the fd_mu_eta oracle (links.rs:164) — your closed form must match the finite difference to 1e-5 across the η grid. This single test catches almost every algebra slip.
  • Round-trip proptests. Mirror log_link_round_trip_in_safe_range (links.rs:260): link(inv_link(η)) ≈ η inside each link's safe η range, and the range/sign invariants (e.g. cloglog/probit inv_link ∈ (0,1)).
  • Boundary saturation. Mirror logit_link_handles_boundary_probabilities (links.rs:149): link(0), link(1), inv_link(±1e6) all finite and in range.

External oracle: R stats::make.link("probit"|"cloglog"|"inverse"|"sqrt"|"cauchit") exposes linkfun, linkinv, and mu.eta. Tabulate them at a grid of η and assert glissando matches. (cloglog/probit/cauchit are all in base R; inverse-square is "1/mu^2".)

Cross-surface bindings BIND-3

Links are selected by string, so there is no new typed surface — the binding work is just accepting the new names. Once step 3 teaches the JSON link parser the new strings, the WASM (src/wasm.rs) and Python (src/python.rs) distribution constructors carry them for free; add the names to each surface's link documentation / enum of accepted strings. No serialization change is needed — links round-trip by name.
