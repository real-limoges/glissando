glissando · structural wrappers — bindings & derivatives

The two items left open after STRUCT-1…STRUCT-4 (censoring, truncation, hurdle, finite mixtures) landed in the Rust crate. Both their preconditions are now met — the typed Rust wrapper API ships (src/distributions/censored.rs, truncated.rs, hurdle.rs, src/fitting/mixture.rs) and so does SER-1 (the serializable FamilyDescriptor) — so neither is blocked any longer.

This guide covers two independent pieces that can be tackled in either order:

  • BIND-D — Python & WASM construction of the structural wrappers.
  • DERIV-D — analytic shape-parameter CDF η-derivatives, retiring the central-difference fallback.

BIND-D · cross-surface construction of the wrappers

The wrappers are stateful — each holds a boxed base Distribution plus per-observation response-side state (a censoring-status vector, truncation limits, mixing weights). Like Binomial and Ocat, they are therefore excluded from from_name (src/distributions/mod.rs:298): a bare family string cannot carry the base family and the per-row state. They are constructed only through the typed Rust API today; this item carries that typed surface to Python and WASM.

The serialization precondition is already met: SER-1 means to_json / from_json bundle a structured FamilyDescriptor (not just a name), and FamilyDescriptor::build() reconstructs the boxed base — so a wrapper built on a surface can round-trip. What is missing is only the surface constructors.

  1. Python classes in src/python.rs — a class per wrapper mirroring the Rust constructor: Censored(base=..., status=...), Truncated(base=..., lower=..., upper=...), Hurdle(base=..., ...), and a mixture entry point over fit_mixture. Accept the base as an already-constructed family object and the response-side state as numpy arrays; marshal to the Array1 the Rust constructor expects. The FamilyType enum in src/ffi.rs is the precedent for passing typed family state the name-based dispatch can't.
  2. WASM constructors in src/wasm.rs — wasm.rs delegates to the glissando::json facade, so expose the wrappers through a JSON shape that names the base family descriptor plus the structural state, and have the facade build the wrapper via FamilyDescriptor. No new serialization format is needed — reuse the descriptor that SER-1 already round-trips.
  3. Worked examples (DOC-3): a right-censored Weibull survival fit and a left-truncated Gaussian, one per surface, in the docs.

DERIV-D · analytic shape-parameter CDF derivatives

Censoring and truncation differentiate the base family's cdf w.r.t. the η of each parameter. The trait hook is Distribution::cdf_eta_derivatives — it returns analytic (∂F/∂η, ∂²F/∂η²) and defaults to empty, in which case src/distributions/structural.rs central-differences the cdf on the η scale (numeric_cdf_grad, structural.rs:49).

Analytic derivatives are already supplied for the location/scale parameters where the CDF is elementary — Gaussian μ/σ, Student-t μ/σ, Gamma μ (see the cdf_eta_derivatives impls in gaussian.rs, student_t.rs, gamma.rs). What still falls back to central differencing is the non-elementary shape parameters:

  • Gamma σ — derivative of the regularized lower incomplete gamma w.r.t. its shape (a series / digamma term).
  • Student-t ν — derivative of the regularized incomplete beta w.r.t. the degrees of freedom.
  • Beta (both shapes) — derivatives of the regularized incomplete beta w.r.t. its parameters.

Each is a matter of differentiating the special function that the family's cdf already calls (statrs::function::gamma::gamma_ur, statrs::function::beta::beta_reg), then mapping ∂F/∂θ → ∂F/∂η via the link's mu_eta and the chain rule — the same shape as the location/scale impls already in tree. Extend each family's cdf_eta_derivatives to return the shape-parameter entries; structural.rs will pick them up automatically and stop central-differencing those rows.

The shape is the same as the location/scale impls already in tree (gamma.rs:136 supplies the μ entry); you add the "sigma" entry alongside it. For Gamma σ, with F = P(α, x), α = 1/σ², x = y/(μσ²):

// Gamma σ (η = ln σ):  F = P(α, x).
//   ∂F/∂σ = (∂P/∂α)·(dα/dσ) + (∂P/∂x)·(dx/dσ)
//   dα/dσ = −2/σ³            dx/dσ = −2x/σ
//   ∂P/∂x = xᵅ·e⁻ˣ / Γ(α)    (the density term — already used for the μ entry)
//   ∂P/∂α = the regularized-lower-incomplete-gamma shape derivative — the ONE new
//           non-elementary piece (a digamma/series term). Then ∂F/∂η_σ = σ·∂F/∂σ.
for i in 0..y.len() {
    if !y[i].is_finite() || y[i] <= 0.0 { continue; }   // flat outside support
    let s = sigma[i].max(MIN_POSITIVE);
    let alpha = 1.0 / (s * s);
    let x = y[i] / (mu[i].max(MIN_POSITIVE) * s * s);
    let dens = (alpha * x.ln() - x - ln_gamma(alpha)).exp();   // ∂P/∂x
    let dp_dalpha = lower_incomplete_gamma_shape_deriv(alpha, x);   // ← todo!()
    let df_dsigma = dp_dalpha * (-2.0 / (s * s * s)) + dens * (-2.0 * x / s);
    d1_sigma[i] = s * df_dsigma;          // chain to η = ln σ
    // d2_sigma[i]: differentiate df_dsigma once more, or fall back numerically
    //              for the second order if the algebra is not worth it.
}

Student-t ν and Beta's two shapes are the analogous derivatives of the regularized incomplete beta w.r.t. its parameters; once lower_incomplete_gamma_shape_deriv / its beta sibling land in src/math.rs, the per-family wiring is this same dozen lines.

Validate with the existing check_score_via_finite_diff harness: the new analytic entries must match the central-difference values they replace to tolerance, on both censored and uncensored rows. This is the single test that catches every algebra slip; gate it across Gamma, Student-t, and Beta.
