glissando · implementation guide

Model selection & comparison — INFER-3, INFER-4, INFER-7. Three items that share one mechanism (compare fitted models by an information criterion or a deviance difference) over one substrate (the −2·loglik and total-EDF already in src/fitting/diagnostics.rs), with the theory derived and the code sketched against the current source. IDs cross-reference docs/ROADMAP.html.

One foundation, two consumers:

INFER-3  (GAIC with arbitrary penalty k)   ← the primitive
   ├──► INFER-4  (stepwise term selection / stepGAIC)   selects by GAIC(k)
   └──► INFER-7  (ANOVA / model comparison)             ranks + LR-tests by deviance

Recommended order: INFER-3 first (a few lines; unblocks the other two), then INFER-4 and INFER-7 in either order.

Substrate already in the crate

  • compute_aic(ll, edf) = −2·ll + 2·edf, compute_bic(ll, edf, n) = −2·ll + log(n)·edf (src/fitting/diagnostics.rs).
  • total_edf(models) -> f64 — fitted effective degrees of freedom, summed over parameters.
  • family.loglik(y, ¶ms) on the Distribution trait — the model log-likelihood.
  • ModelDiagnostics { total_edf, aic, bic, log_likelihood, n_obs, .. } from GamlssModel::diagnostics(family, y).

The fitting entry points the selection loop drives: GamlssModel::fit(data, y, &formula, family) and fit_with_config(data, y, weights, &formula, family, config), where a Formula is a HashMap<String, Vec<Term>> built with .with_terms(param, terms) / .add_terms(param, terms), and each Term (Intercept / Linear{col_name} / Smooth(..)) reports a stable term_name().

INFER-3 — GAIC with arbitrary penalty k

File: src/fitting/diagnostics.rs (primitive) + GamlssModel method in src/lib.rs.

Why a penalized log-likelihood

Maximized log-likelihood always rises as terms are added, so it cannot choose a model — it must be penalized for complexity. The global deviance and its generalized information criterion are

GD = −2·ℓ̂ (gamlss "global deviance"; no saturated-model subtraction) GAIC(k) = GD + k·df = −2·ℓ̂ + k·df

The two classical choices come from different first principles:

  • AIC (k = 2): an estimate of the expected Kullback–Leibler divergence between the fitted and true densities; the 2·df term corrects the optimism of the in-sample log-likelihood (Akaike). Targets predictive accuracy.
  • BIC / SBC (k = log n): the Laplace approximation to −2·log of the Bayesian marginal likelihood; the log(n)·df term is the Occam factor. Targets the true model and is consistent. Penalizes complexity harder than AIC once n ≥ 8.
common k:  2 (AIC) · log n (BIC) · 3.84 ≈ χ²1,0.95 · 2·log log n (Hannan–Quinn-ish)

Crucially, df is the effective degrees of freedom, not the raw coefficient count: for a penalized smooth it is tr(F), the trace of the smoother / hat operator, which is fractional. glissando already computes and stores it as total_edf — so GAIC drops in directly.

Code

Add the primitive and re-express AIC/BIC through it so there is a single definition every downstream score inherits:

// src/fitting/diagnostics.rs

/// Generalized AIC: `−2·loglik + k·edf`. `k = 2` is AIC, `k = log(n)` is BIC.
pub fn compute_gaic(log_likelihood: f64, total_edf: f64, k: f64) -> f64 {
    -2.0 * log_likelihood + k * total_edf
}

pub fn compute_aic(ll: f64, edf: f64) -> f64          { compute_gaic(ll, edf, 2.0) }
pub fn compute_bic(ll: f64, edf: f64, n: usize) -> f64 { compute_gaic(ll, edf, (n as f64).ln()) }
// src/lib.rs — on GamlssModel

/// Generalized AIC at penalty `k`. `k = 2` ≡ `diagnostics(..).aic`;
/// `k = (n as f64).ln()` ≡ `.bic`. Use the response `y` the model was fit on.
pub fn gaic<D: Distribution + ?Sized>(
    &self, family: &D, y: &Array1<f64>, k: f64,
) -> Result<f64, GamlssError> {
    let params: HashMap<&str, &Array1<f64>> =
        self.models.iter().map(|(p, f)| (p.as_str(), &f.fitted_values)).collect();
    let ll = family.loglik(y, ¶ms)?;
    let edf = fitting::diagnostics::total_edf(&self.models);
    Ok(fitting::diagnostics::compute_gaic(ll, edf, k))
}

Keep the single-source refactor in this item — it guarantees AIC, BIC, and every stepGAIC/ANOVA score stay consistent, and the existing AIC/BIC doctests in diagnostics.rs already pin it.

Tests

  • gaic(.., 2.0) equals diagnostics.aic; gaic(.., (n).ln()) equals .bic.
  • Monotone in k: larger k ⇒ larger GAIC for the same fit (edf > 0).
  • Two fits, equal log-likelihood: the lower-EDF one has the lower GAIC at every k > 0.

INFER-4 — Stepwise term selection (stepGAIC analog)

File: new module src/fitting/selection.rs + a convenience method on GamlssModel. Depends on INFER-3.

The search

Stepwise selection is greedy local search over a discrete neighbourhood of models. Let the neighbourhood N(M) be all models reachable from M by adding or dropping one term. At each step evaluate the move score and take the best improving one:

Δ(M → M′) = GAICk(M′) − GAICk(M) M ← argminM′ ∈ N(M) GAICk(M′) while min Δ < −ε

For a single added term with Δdf extra effective df, the move is accepted iff it lowers the deviance by more than the penalty it costs:

accept ⟺ GD(M) − GD(M′) > k·Δdf ( = the deviance drop must beat k per df )

The k is the selection knob: k=2 (AIC) is permissive, k=log n (BIC) is parsimonious. The search is pure orchestration over fit_with_config + the INFER-3 score — no new numerics.

Shapes

// src/fitting/selection.rs

/// Which moves the search may make, per distribution parameter.
pub struct StepScope {
    pub param: String,            // "mu", "sigma", …
    pub candidates: Vec<Term>,     // Linear / Smooth terms eligible to add or drop
}

#[derive(Clone, Copy)]
pub enum Direction { Forward, Backward, Both }

pub struct StepRecord { pub move_: String, pub gaic: f64, pub edf: f64 }   // one accepted step

pub struct StepResult {
    pub model: GamlssModel,
    pub formula: Formula,
    pub trace: Vec<StepRecord>,   // the accepted path, in order
}

pub fn step_gaic<D: Distribution + ?Sized>(
    data: &DataSet, y: &Array1<f64>, family: &D,
    start: Formula, scope: &[StepScope],
    k: f64, direction: Direction, config: FitConfig,
) -> Result<StepResult, GamlssError>;

Implementation

// formula mutation helpers — identity by Term::term_name()
fn has_term(f: &Formula, param: &str, t: &Term) -> bool {
    f.0.get(param).map_or(false, |ts| ts.iter().any(|x| x.term_name() == t.term_name()))
}
fn with_added(mut f: Formula, param: &str, t: &Term) -> Formula {
    let mut ts = f.0.get(param).cloned().unwrap_or_default();
    ts.push(t.clone());
    f.with_terms(param, ts)                      // rebuilds the param's Vec<Term>
}
fn with_dropped(mut f: Formula, param: &str, t: &Term) -> Formula {
    let ts = f.0.get(param).cloned().unwrap_or_default()
        .into_iter().filter(|x| x.term_name() != t.term_name()).collect();
    f.with_terms(param, ts)
}

pub fn step_gaic<D: Distribution + ?Sized>(
    data: &DataSet, y: &Array1<f64>, family: &D,
    start: Formula, scope: &[StepScope],
    k: f64, direction: Direction, config: FitConfig,
) -> Result<StepResult, GamlssError> {
    const EPS: f64 = 1e-6;                                   // guard against churn on ties
    let mut current = start;
    let mut model = GamlssModel::fit_with_config(data, y, None, ¤t, family, config.clone())?;
    let mut best_gaic = model.gaic(family, y, k)?;
    let mut trace = Vec::new();

    loop {
        // 1. enumerate candidate moves in a DETERMINISTIC order (reproducibility).
        let mut moves: Vec<(String, &Term, bool)> = Vec::new();   // (param, term, is_add)
        for s in scope {
            for t in &s.candidates {
                let present = has_term(¤t, &s.param, t);
                match direction {
                    Direction::Forward  if !present => moves.push((s.param.clone(), t, true)),
                    Direction::Backward if  present => moves.push((s.param.clone(), t, false)),
                    Direction::Both => moves.push((s.param.clone(), t, !present)),
                    _ => {}
                }
            }
        }

        // 2. score every move; a fit that errors (non-convergence, singular) is SKIPPED.
        let mut best: Option<(f64, f64, String, Formula)> = None;
        for (param, t, is_add) in moves {
            let trial = if is_add { with_added(current.clone(), ¶m, t) }
                        else       { with_dropped(current.clone(), ¶m, t) };
            let fit = match GamlssModel::fit_with_config(data, y, None, &trial, family, config.clone()) {
                Ok(m) => m, Err(_) => continue,
            };
            let (g, e) = (fit.gaic(family, y, k)?, fitting::diagnostics::total_edf(&fit.models));
            let label = format!("{} {} on {}", if is_add {"+"} else {"−"}, t.term_name(), param);
            if best.as_ref().map_or(true, |(bg, ..)| g < *bg) {
                best = Some((g, e, label, trial));
                // keep the fitted model too in practice — elided here for brevity
            }
        }

        // 3. accept the best improving move, else stop at the local optimum.
        match best {
            Some((g, e, label, trial)) if g < best_gaic - EPS => {
                best_gaic = g;
                current = trial;
                model = GamlssModel::fit_with_config(data, y, None, ¤t, family, config.clone())?;
                trace.push(StepRecord { move_: label, gaic: g, edf: e });
            }
            _ => break,
        }
    }
    Ok(StepResult { model, formula: current, trace })
}

Cost & scope discipline. Each step is O(#candidate moves) full refits and the search runs O(#accepted steps) of those — keep it greedy and single-term (no look-ahead, no interaction synthesis), matching gamlss's stepGAIC. Cache the fitted model from step 2 instead of refitting the winner in step 3 (the sketch refits for brevity). Document that the result is a local optimum, and that trace records the path so callers can audit it.

Tests

  • Recovery: simulate y ~ x1 with noise columns x2, x3; forward step_gaic selects x1 and rejects the noise at a sensible k.
  • Backward from the full model drops the noise columns to the same selection.
  • Determinism: identical inputs ⇒ identical trace (relies on the fixed move ordering).
  • Monotone trace: each accepted step strictly lowers GAIC(k).

INFER-7 — ANOVA / model comparison

File: src/fitting/selection.rs (or a sibling comparison.rs). Shares the deviance/EDF primitives with INFER-3.

Two facilities under one roof, matching anova() for gamlss/mgcv objects.

1 · Information-criterion table (non-nested OK)

Tabulate a set of models by EDF, global deviance, and GAIC(k) — a ranking, no test. Works for any models fit to the same response, nested or not (this is how you compare different families or non-nested term sets).

pub struct IcRow { pub label: String, pub edf: f64, pub global_deviance: f64, pub gaic: f64 }

pub fn ic_table<D: Distribution + ?Sized>(
    models: &[(&str, &GamlssModel)], family: &D, y: &Array1<f64>, k: f64,
) -> Result<Vec<IcRow>, GamlssError> {
    models.iter().map(|(label, m)| {
        let params: HashMap<&str, &Array1<f64>> =
            m.models.iter().map(|(p, f)| (p.as_str(), &f.fitted_values)).collect();
        let ll  = family.loglik(y, ¶ms)?;
        let edf = fitting::diagnostics::total_edf(&m.models);
        Ok(IcRow {
            label: (*label).to_string(),
            edf,
            global_deviance: -2.0 * ll,
            gaic: fitting::diagnostics::compute_gaic(ll, edf, k),
        })
    }).collect()
}

2 · Likelihood-ratio test (nested models)

For a small model M0 nested in a big model M1, Wilks' theorem gives the asymptotic null distribution of the deviance difference:

LR = 2·(ℓ̂1 − ℓ̂0) = GD0 − GD1  →d  χ²ν under M0,  ν = df1 − df0 p = P(χ²ν > LR) = 1 − Fχ²,ν(LR) = Q(ν/2, LR/2)

The χ² survival function reuses the regularized upper incomplete gamma already in the crate — gamma_ur(ν/2, LR/2) — so no new dependency, and it dovetails with the incomplete-gamma identity used for the Poisson/Gamma CDFs in the TRAIT-1 guide. (Equivalently 1.0 − statrs::distribution::ChiSquared::new(ν)?.cdf(LR).)

use statrs::function::gamma::gamma_ur;

pub struct LrTest { pub lr_stat: f64, pub df: f64, pub p_value: f64 }

pub fn lr_test<D: Distribution + ?Sized>(
    small: &GamlssModel, big: &GamlssModel, family: &D, y: &Array1<f64>,
) -> Result<LrTest, GamlssError> {
    let ll = |m: &GamlssModel| -> Result<f64, GamlssError> {
        let p: HashMap<&str, &Array1<f64>> =
            m.models.iter().map(|(k, f)| (k.as_str(), &f.fitted_values)).collect();
        family.loglik(y, &p)
    };
    let (ll0, ll1) = (ll(small)?, ll(big)?);
    let (e0, e1) = (fitting::diagnostics::total_edf(&small.models),
                    fitting::diagnostics::total_edf(&big.models));
    let (lr, df) = (2.0 * (ll1 - ll0), e1 - e0);

    // nesting guard: big must be the larger, better-fitting model.
    if df <= 0.0 || lr < -1e-6 {
        return Err(GamlssError::Input(
            "lr_test expects `small` nested in `big` (edf_big > edf_small, loglik_big ≥ loglik_small)".into()));
    }
    let p_value = gamma_ur(df / 2.0, lr.max(0.0) / 2.0);          // P(χ²_df > LR)
    Ok(LrTest { lr_stat: lr, df, p_value })
}

Honest caveat — fractional EDF. Penalized smooths have non-integer effective df, so ν = df₁ − df₀ is generally fractional and the χ² reference is approximate (exactly the caveat anova.gam / summary.gam carry in mgcv; it ties to INFER-5). The continuous-ν χ² above (via gamma_ur) handles fractional df gracefully. Document the approximation, and rely on the nesting guard so a mis-ordered or non-nested pair returns GamlssError::Input rather than a meaningless negative statistic.

Tests

  • IC table orders a clearly-better and clearly-worse fit correctly by both global_deviance and gaic.
  • LRT null calibration: adding a pure-noise column to a correct model gives small LR and a roughly uniform p-value across simulated datasets.
  • LRT power: adding a genuinely predictive term gives large LR and a tiny p-value.
  • Known-value: for unpenalized (integer-df) nested linear models, lr_stat and p_value match R's anova(m0, m1, test="Chisq") within tolerance.
  • Nesting guard: a non-nested or mis-ordered pair returns GamlssError::Input.
