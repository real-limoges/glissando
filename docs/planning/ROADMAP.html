glissando · feature-completeness roadmap

Target: parity with R gamlss / mgcv as a GAMLSS engine. Current state (v0.1.0): RS outer loop with REML/GCV/Fellner-Schall, step-halving, and global-deviance convergence; P-spline 1D, CR-spline 1D, 2D tensor, random intercept; 12 base distributions with cdf/pdf/quantile (including the Box-Cox family BCCG/BCT/BCPE and Weibull), plus the Censored / Truncated / Hurdle structural wrappers; 10 links with mu_eta and mu_eta2, any of which fits correctly on any parameter (bar two documented exceptions; see B); native + WASM + Python + JSON surfaces; AIC/BIC/EDF + GAIC(k), stepwise selection, ANOVA / LR test; Pearson, response, and randomized-quantile residuals; centiles / quantile prediction; posterior sampling. Nothing is published. How to read this: the roadmap is laid out two ways. Part 1 groups every gap into workstreams of similar work, which is good for assigning and batching. Part 2 is a single flat stack-ranking by importance, which is good for deciding what to do next. The same items appear in both, and IDs like DIST-1 are shared so the two views cross-reference.

Recently shipped

Six workstreams' worth of design-level implementation guides have now landed in the source, with tests, bindings, and docs. The items below are done. They remain in Part 1 and Part 2 (marked ✓) for cross-reference and to show what each unblocks.

Part 1 · Grouped by workstream

A · Distribution trait foundations

The single highest-leverage area. The Distribution trait (src/distributions/mod.rs) now exposes cdf, pdf, quantile, and is_discrete alongside derivatives, loglik, variance, expected_value, initial_value, and default_link. These unlocked centiles, randomized quantile residuals, and full-distribution prediction: the defining outputs of GAMLSS.

ID Item
TRAIT-1 ✓ cdf(y, params), pdf(y, params), quantile(p, params) (plus is_discrete) on the Distribution trait, implemented for all families.
TRAIT-2 ✓ Link derivative method (mu_eta / g'(μ)) on the Link trait (finite-difference default plus analytic overrides on all ten built-ins). Unblocks B. The generic-weight refactor that routes derivatives through mu_eta landed 2026-08-01: derivatives now returns natural-scale (∂l/∂θ, i_θ) and the chain rule is applied once, generically, from the link the caller selected. A second derivative mu_eta2 was added alongside it for the structural wrappers, whose observed information is not link-invariant.

B · Link functions

Identity, Log, Logit, and FlooredLog plus the standard set below now exist (src/distributions/links.rs), each with an analytic mu_eta validated against finite differences and selectable by name on every surface. TRAIT-2 (the mu_eta hinge) unblocked them. The six canonical links (LINK-1 through LINK-6) are done; the one remaining item is the shifted / bounded "own"-logit variant. Implementation guide: bounded / shifted links (LINK-7).

✓ now means "fits correctly", not merely "constructible and selectable". Until 2026-08-01 every family hardcoded the chain rule for its own default link inside Distribution::derivatives, and fitting/scoring.rs never corrected for the link the caller actually chose. Since the IRLS fixed point solves Σᵢ (dμ/dη)ᵢ·(∂l/∂μ)ᵢ·xᵢⱼ = 0, a wrong dμ/dη moved the estimate, and a wrong weight moved SEs, EDF, and λ selection. Measured against an independent maximum-likelihood optimizer (tests/link_mle_oracle.rs), the fitted log-likelihood fell short of the true maximum by 45.5 for gamma/inverse, 8.5e-3 for binomial/probit, 1.0e-4 for poisson/sqrt, and 6.4e-5 for binomial/cloglog.

All four gaps are closed. derivatives now returns natural-scale (∂l/∂θ, i_θ); eta_derivatives applies u = mu_eta·∂l/∂θ and w = mu_eta²·i_θ once, generically, from the resolved link; the structural wrappers chain their CDF gradients with the second-order rule ∂²F/∂η² = mu_eta²·∂²F/∂θ² + mu_eta2·∂F/∂θ; and MIN_WEIGHT is now applied in exactly one place, downstream of the multiply, which also fixed the weight_floor_hits diagnostic (Altitude #4). The four oracle cases run un-#[ignore]d as standing acceptance gates, alongside per-family finite-difference checks under non-default links and saturated-fixture finiteness gates. Default links were unaffected throughout and are verified by the same oracle.

Two documented exceptions. FitConfig::links now rejects an override it cannot honor rather than silently ignoring it (Distribution::allows_link_override): every Ocat parameter, because its params["mu"] holds η and its threshold Jacobian is exp(η_k) only under the log link; and Student-t ν, because its floor is a KKT-style aggregate projection written against FlooredLogLink. An override naming a parameter the family does not have is also an error now; it used to be a silent no-op. No domain checking is done: a logit link on a Poisson μ is accepted and produces nonsense.

ID Item
LINK-1 ✓ Probit (Φ⁻¹), the binary alternative to logit.
LINK-2 ✓ Complementary log-log (cloglog), for binomial / discrete survival.
LINK-3 ✓ Inverse / reciprocal (1/μ), the classical Gamma canonical link.
LINK-4 ✓ Inverse-square (1/μ²), the Inverse Gaussian canonical link.
LINK-5 ✓ Sqrt, the Poisson variance-stabilizing link.
LINK-6 ✓ Cauchit (heavy-tailed bounded link); shifted / bounded "own" logit variants remain.

C · Distribution families

Implemented: Gaussian, Gamma, Poisson, Negative Binomial, Beta, Student-t, Binomial, Ocat (2–5 levels), the Box-Cox family BCCG / BCT / BCPE (DIST-1), and Weibull (the first DIST-2 family). The catalog below is what gamlss.dist ships, grouped by family type.

Implementation guides: continuous & count families covers DIST-2 / DIST-3 / DIST-4; zero-inflated & Tweedie covers DIST-5 / DIST-7 / DIST-6; and continuous-positive, worked end-to-end writes one DIST-2 family (Weibull) in full copy-paste Rust. (DIST-1 Box-Cox is the shipped worked example all of these copy.)

ID Item
DIST-1 ✓ Box-Cox / power family, the signature GAMLSS distributions: BCCG (Box-Cox Cole-Green), BCT (Box-Cox-t), BCPE (Box-Cox power exponential). Powers LMS centile / growth-chart curves.
DIST-2 Common continuous-positive: Weibull is ✓ done (src/distributions/weibull.rs); Inverse Gaussian (IG), Lognormal (LOGNO), Exponential, Generalized Gamma (GG), and Pareto remain. Activates the just-shipped inverse / inverse-square / sqrt canonical links.
DIST-3 Skew / kurtotic continuous: Skew Normal (SN1/SN2), Skew-t (ST1–ST5), Sinh-Arcsinh (SHASH), Johnson SU (JSU), Power Exponential (PE), Generalized t (GT).
DIST-4 Count families: Geometric, Logarithmic, Beta-Binomial, Double Poisson, Poisson-Inverse-Gaussian (PIG), Sichel, Delaporte.
DIST-5 Zero-inflated / zero-adjusted: ZIP, ZINBI, Zero-Adjusted Gamma (ZAGA), Zero-Adjusted IG (ZAIG), Zero/One-Inflated Beta (BEINF/BEZI/BEOI).
DIST-6 Ocat generalization beyond the 2–5 category cap (src/distributions/ocat.rs panics outside 2–5).
DIST-7 Tweedie: compound Poisson-Gamma for zero-inflated continuous data. A high-value real-world use case: insurance claims, rainfall, e-commerce spend; the canonical "exact zeros plus a positive continuous part" distribution. Carries a power-variance parameter p (1<p<2); unlike DIST-2 it has no closed-form density, so loglik/cdf need a series or saddlepoint evaluation, making it a focused mini-project closer to the Box-Cox derivative work than to the easy positive-continuous template.

D · Structural / likelihood modeling

The trait has no hooks for these; they need new machinery, not just new families. STRUCT-1 through STRUCT-4 (the wrapper-distribution plus response-side-state approach) have landed in the Rust crate. Implementation guide: structural wrappers: bindings & derivatives covers the two follow-on items (Python/WASM construction; analytic shape-parameter CDF derivatives).

E · Smooth terms & splines

The Smooth enum (src/terms.rs) has PSpline1D, CrSpline1D, TensorProduct (2D only), and RandomEffect (intercept only). Each new variant needs an enum case, a basis in src/splines/, and an assembler.rs block mapping. Implementation guide: smooth terms & splines covers SMOOTH-1 (cyclic) / SMOOTH-2 (thin-plate) / SMOOTH-4 (random slopes).

ID Item
SMOOTH-1 Cyclic splines (mgcv bs="cc"): seasonal / periodic.
SMOOTH-2 Thin-plate regression splines (bs="tp").
SMOOTH-3 By-factor / varying-coefficient smooths (s(x, by=f)).
SMOOTH-4 Random slopes (only random intercepts exist today).
SMOOTH-5 Monotonic / shape-constrained (SCAM-style) splines.
SMOOTH-6 Tensor products of dimension >2 and interaction-only ti() tensors.
SMOOTH-7 Markov random fields (bs="mrf"), adaptive (bs="ad"), factor-smooth interactions (bs="fs"), soap-film.

F · Fitting engine robustness

fit_gamlss (src/fitting/mod.rs) is RS-only with per-parameter coefficient-change convergence; stability comes from weight floors plus step caps. Implementation guide: fitting algorithms: CG & grid λ covers FIT-3 (Cole-Green) / FIT-4 (grid λ).

ID Item
FIT-1 ✓ Step-halving / line-search on the global deviance in the RS loop.
FIT-2 ✓ Global-deviance outer convergence criterion (in addition to Δβ), surfaced via FitConfig::gd_tolerance and FitDiagnostics::final_deviance.
FIT-3 CG (Cole-Green) algorithm for cross-parameter derivative coupling; gamlss's second fitting algorithm, for when RS mixes slowly.
FIT-4 GAIC-based / grid ("magic"-style) λ selection as an alternative to the L-BFGS criteria.

Critical path

TRAIT-1 → (INFER-1, INFER-2), TRAIT-2 → links (LINK-1..6), the signature Box-Cox family (DIST-1), and the data / formula ergonomics (DATA-1..5) have all landed. TRAIT-1 was the single most important item in the roadmap because almost everything statistically distinctive about GAMLSS depended on it. With the foundations, links, and Box-Cox catalog shipped, the critical path now runs through the rest of the distribution catalog, chiefly the continuous-positive families (DIST-2, whose first family Weibull has landed, and whose remaining members would exercise the new inverse / inverse-square / sqrt links) and the high-value zero-inflated continuous case Tweedie (DIST-7).
