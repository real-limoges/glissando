glissando · feature-completeness roadmap

Target: parity with R gamlss / mgcv as a GAMLSS engine. Presented two ways — Part 1 groups every gap into workstreams of similar work (good for assigning / batching); Part 2 is a single flat stack-ranking by importance (good for deciding what to do next). The same items appear in both; IDs like DIST-1 are shared so you can cross-reference.

Current state (v0.1.0): RS outer loop with REML/GCV/Fellner-Schall, step-halving, and global-deviance convergence; P-spline 1D, CR-spline 1D, 2D tensor, random intercept; 8 distributions with cdf/pdf/quantile; 4 links with mu_eta; native + WASM + Python + JSON surfaces; AIC/BIC/EDF + GAIC(k), stepwise selection, ANOVA / LR test; Pearson, response, and randomized-quantile residuals; centiles / quantile prediction; posterior sampling. Nothing is published.

✅ Recently shipped

Three workstreams' worth of design-level implementation guides have now landed in the source (with tests, bindings, and docs). The items below are done; they remain in Part 1 / Part 2 (marked DONE) for cross-reference and to show what each unblocks.

trait + infer TRAIT-1 INFER-1 INFER-2 TRAIT-2 — distributional cdf/pdf/quantile on all 8 families, randomized quantile residuals, centiles / quantile prediction, and the mu_eta link derivative.
model selection INFER-3 INFER-4 INFER-7 — GAIC(k), stepwise term selection (stepGAIC), and ANOVA / likelihood-ratio model comparison.
fitting robustness FIT-1 FIT-2 — step-halving / line-search on the global deviance, and global-deviance outer convergence in the RS loop.

Part 1 — Grouped by workstream

A · Distribution trait foundations

The single highest-leverage area: the Distribution trait (src/distributions/mod.rs) now exposes cdf, pdf, quantile, and is_discrete alongside derivatives, loglik, variance, expected_value, initial_value, default_link. These unlocked centiles, randomized quantile residuals, and full-distribution prediction — the defining outputs of GAMLSS.

TRAIT-1✓ cdf(y, params), pdf(y, params), quantile(p, params) (+ is_discrete) on the Distribution trait, implemented for all 8 families.
TRAIT-2✓ Link derivative method (mu_eta / g'(μ)) on the Link trait (finite-difference default + analytic overrides for Identity/Log/FlooredLog/Logit). Unblocks B; the generic-weight refactor that routes derivatives through it is folded into the link-expansion items.

B · Link functions

Only Identity, Log, Logit, FlooredLog exist (src/distributions/links.rs). Missing the standard set below. TRAIT-2 (the mu_eta hinge needed for clean integration) has landed, so these are now unblocked.

LINK-1Probit (Φ⁻¹) — binary alternative to logit.
LINK-2Complementary log-log (cloglog) — binomial / discrete survival.
LINK-3Inverse / reciprocal (1/μ) — classical Gamma canonical link.
LINK-4Inverse-square (1/μ²) — Inverse Gaussian canonical link.
LINK-5Sqrt — Poisson variance-stabilizing link.
LINK-6Cauchit, log-log, and bounded "own" / shifted-logit variants.

C · Distribution families

Implemented: Gaussian, Gamma, Poisson, Negative Binomial, Beta, Student-t, Binomial, Ocat (2–5 levels). The catalog below is what gamlss.dist ships, grouped by family type.

DIST-1Box-Cox / power family — the signature GAMLSS distributions: BCCG (Box-Cox Cole-Green), BCT (Box-Cox-t), BCPE (Box-Cox power exponential).
DIST-2Common continuous-positive: Inverse Gaussian (IG), Weibull, Lognormal (LOGNO), Exponential, Generalized Gamma (GG), Pareto.
DIST-3Skew / kurtotic continuous: Skew Normal (SN1/SN2), Skew-t (ST1–ST5), Sinh-Arcsinh (SHASH), Johnson SU (JSU), Power Exponential (PE), Generalized t (GT).
DIST-4Count families: Geometric, Logarithmic, Beta-Binomial, Double Poisson, Poisson-Inverse-Gaussian (PIG), Sichel, Delaporte.
DIST-5Zero-inflated / zero-adjusted: ZIP, ZINBI, Zero-Adjusted Gamma (ZAGA), Zero-Adjusted IG (ZAIG), Zero/One-Inflated Beta (BEINF/BEZI/BEOI).
DIST-6Ocat generalization beyond the 2–5 category cap (src/distributions/ocat.rs panics outside 2–5).

D · Structural / likelihood modeling

The trait has no hooks for these; they need new machinery, not just new families.

STRUCT-1Censoring (left / right / interval) — survival-style response.
STRUCT-2Truncation (left / right / interval) bounds.
STRUCT-3Hurdle / two-part structure (generalizes zero-inflation cleanly).
STRUCT-4Finite mixture models (component machinery).

E · Smooth terms & splines

Smooth enum (src/terms.rs) has PSpline1D, CrSpline1D, TensorProduct (2D only), RandomEffect (intercept only). Each new variant needs: enum case + splines.rs basis + assembler.rs block mapping.

SMOOTH-1Cyclic splines (mgcv bs="cc") — seasonal / periodic.
SMOOTH-2Thin-plate regression splines (bs="tp").
SMOOTH-3By-factor / varying-coefficient smooths (s(x, by=f)).
SMOOTH-4Random slopes (only random intercepts exist today).
SMOOTH-5Monotonic / shape-constrained (SCAM-style) splines.
SMOOTH-6Tensor products of dimension >2 and interaction-only ti() tensors.
SMOOTH-7Markov random fields (bs="mrf"), adaptive (bs="ad"), factor-smooth interactions (bs="fs"), soap-film.

F · Fitting engine robustness

fit_gamlss (src/fitting/mod.rs) is RS-only with per-parameter coefficient-change convergence; stability comes from weight floors + step caps.

FIT-1✓ Step-halving / line-search on the global deviance in the RS loop.
FIT-2✓ Global-deviance outer convergence criterion (in addition to Δβ), surfaced via FitConfig::gd_tolerance and FitDiagnostics::final_deviance.
FIT-3CG (Cole-Green) algorithm for cross-parameter derivative coupling — gamlss's second fitting algorithm, for when RS mixes slowly.
FIT-4GAIC-based / grid ("magic"-style) λ selection as an alternative to the L-BFGS criteria.

G · Model selection & inference

Present: AIC, BIC, total / per-param / per-term EDF, collapse warnings (src/fitting/diagnostics.rs).

INFER-1✓ Randomized (normalized) quantile residuals — gamlss's default residual (GamlssModel::quantile_residuals).
INFER-2✓ Centile / quantile prediction (centiles() / quantile_prediction()); full-distribution prediction is already predict().
INFER-3✓ GAIC with arbitrary penalty k (compute_gaic / GamlssModel::gaic).
INFER-4✓ Stepwise term selection (step_gaic: forward / backward / both).
INFER-5Approximate p-values / significance tests for smooth terms (summary.gam Tr/Wald analog).
INFER-6Confidence intervals for fitted curves and coefficients.
INFER-7✓ ANOVA / model-comparison facility (ic_table + likelihood-ratio lr_test).

H · Diagnostics & plotting

Present: Pearson + response residuals, Display summary.

DIAG-1Worm plots (the gamlss diagnostic) — needs INFER-1.
DIAG-2Q-Q plots and detrended Q-Q — needs INFER-1.
DIAG-3Deviance residuals.
DIAG-4Goodness-of-fit statistics (Filliben correlation, Z/Q stats).
DIAG-5Term-effect plotting data (partial-effect curves + CI bands) — needs INFER-6.

I · Data handling & formula

DataSet is HashMap<String, Array1<f64>> (all f64); Formula is term lists.

DATA-1✓ Factor / categorical type with treatment / sum-to-zero contrast coding (Term::factor / Contrast); levels resolve at fit and replay at predict.
DATA-2✓ Interaction terms (x:z, x*z) via row-Kronecker products (Term::interaction); factor×continuous and factor×factor included.
DATA-3✓ Offsets (Term::offset) — fixed per-row carry η = Xβ + offset threaded through fit and predict.
DATA-4✓ Missing-data / NA handling (FitConfig::na_action: DropRows default à la na.omit, or Fail).
DATA-5✓ String formula parser (Formula::parse / from_strings, "y ~ s(x) + factor(g) + x:z") — exposed on native / JSON / WASM / Python.

J · API ergonomics

Formula construction is raw enum struct-literals.

API-1Fluent builder / helper constructors (s("x"), linear("z"), random("g")) or string-formula DSL (overlaps DATA-5).
API-2Named model.summary() returning a struct (today only via Display).

Part 2 — Stack-ranked by importance (R gamlss parity)

Ranked so that each item's prerequisites sit above it, and "what makes GAMLSS GAMLSS" (flexible distributions, centiles, quantile residuals) sits near the top.

  1. TRAIT-1 — ✓ cdf / pdf / quantile on the Distribution trait.
    Foundational; unlocked centiles, quantile residuals, full-distribution prediction.
  2. INFER-1 — ✓ Randomized quantile residuals (gamlss's default residual).
  3. INFER-2 — ✓ Centile / quantile prediction (the signature GAMLSS output).
  4. DIST-1 — Box-Cox family (BCCG / BCT / BCPE), the distributions GAMLSS is known for.
  5. DIST-2 — Common continuous-positive families (IG, Weibull, Lognormal, Exponential, GG).
  6. DIST-5 — Zero-inflated / zero-adjusted families (ZIP, ZINBI, ZAGA, BEINF) — very common in real count / semicontinuous data.
  7. TRAIT-2 — ✓ Link derivative method (mu_eta). Unblocks the link expansion.
  8. LINK-1..5 — Probit, cloglog, inverse, inverse-square, sqrt links.
  9. DIST-3 — Skew / kurtotic families (SN, ST, SHASH, JSU, PE).
  10. DIST-4 — Additional count families (Geometric, Beta-Binomial, PIG, Sichel, Delaporte, Logarithmic).
  11. DIAG-1 / DIAG-2 — Worm plots and Q-Q plots (the core gamlss diagnostics).
  12. INFER-3 / INFER-4 — ✓ GAIC(k) and stepwise term selection (stepGAIC).
  13. FIT-1 / FIT-2 — ✓ Step-halving + global-deviance convergence (robustness for the heavy-tailed / skew families).
  14. INFER-5 / INFER-6 / INFER-7 — Smooth-term p-values, confidence intervals; ANOVA (INFER-7) ✓ done.
  15. DATA-1 / DATA-2 / DATA-3 — ✓ Factor / categorical encoding, interactions, offsets.

Critical path

TRAIT-1 → (INFER-1, INFER-2) and TRAIT-2 → links — all landed. TRAIT-1 was the single most important item in the roadmap because almost everything statistically distinctive about GAMLSS depended on it; with it and its dependents shipped, the critical path now runs through the distribution catalog (DIST-*) and the link expansion (LINK-*), both unblocked.
